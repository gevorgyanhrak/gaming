# Court card art

The jacks, queens and kings drawn inside `CardFace` (English pattern) are by **Dmitry Fomin**, from Wikimedia
Commons, released under **CC0 1.0** (public domain dedication):
https://commons.wikimedia.org/wiki/Category:English_pattern_playing_cards_deck_(Dmitry_Fomin)

Changes made here: editor metadata removed, numbers rounded, a viewBox added, and the red (#ff5555) set to the
table's card red (#c1121f). File names are our card codes (`KH.svg` = king of hearts).
